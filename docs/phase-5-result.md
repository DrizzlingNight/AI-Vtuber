這個工作階段建立時，Copilot App 就已配置隔離 worktree 與工作分支；
後續只是將分支更名為 `claireke0329-phase-5-orchestration`。

上一輪只做了工作分支的提交，**沒有執行合併或推送**，所以主目錄看不到這些修改。
這是尚未完成的交付步驟，不是已經同步，也不是 Git 技術上不能同步。
先前的說明沒有把「程式開發」「實機驗收」「同步 main」三件事分開交代清楚。
